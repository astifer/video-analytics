# Runner

Модуль для обработки изображений: получение потока, отправка в инференс, пост/преобработка, (публикация предсказаний?)

### Требуемые задачи
- **чтение кадра** - живой поток с камер наблюдения в Пхукете
- **препроцессинг (optional)** - подготовка полученного кадра к отправке (BGR2RGB \ resize \ ...) - скорее всего не будет
- **отправка кадра** - отправка кадра в inference
- **получение результата** - чтение результатов с предсказаниями
- **публикация результата** - доступность событий (предсказаний) на стороне api. Куда отправить результаты?
