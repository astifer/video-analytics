# Инференс сервис

Сервис, хранящий и запускающий модель. К нему приходят сообщения от runner'a (с изображениями). Выдает результаты работы модели - боксы и лейблы для картинок

### Требуемые задачи

- **чтение кадра** - получение кадра
- **предсказание** - inference при помощи модели yolo
- **отправка результатов** - возврат результатов в runner
